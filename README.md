## ディレクトリの命名規則
### 最上位階層
原則として以下の分類に従う。ただし、例外もある。
- Permanent: "常設中のコンテスト"内にあるコンテスト
- ATC: カテゴリが"AtCoder Typical Contest"のコンテスト
- ABC: "AtCoder Beginner Contest"や、Rated対象が"ABCクラス"のコンテスト
- AWC: カテゴリが"AtCoder Weekday Contest"のコンテスト
- ARC: "AtCoder Regular Contest"や、Rated対象が"ARCクラス"のコンテスト
- AGC: Rated対象が"AGCクラス"のコンテスト
- AHC: Rated対象が"AHCクラス"のコンテスト

ちなみに上記の順番は、取り組む優先度が高い(と自分が勝手に思っている)コンテストの分類の順番。

### ディレクトリ名
コンテストのURLの、"https://atcoder.jp/contests/XXX"のXXXの部分

### ファイル名
コンテストのURLの、"https://atcoder.jp/contests/XXX/tasks/xxx"のxxxの部分<br>
別解などを用意している場合は、ファイル名の末尾に空白と数字を付ける。<br>
また、"常設中のコンテスト"(Permanent)にて他のコンテストの問題を使用していたり、問題の命名規則が"a, b, c, ..."になっていないことにより、問題の順番とURLの辞書順の順番が一致しないことがある。その場合はファイル名を問題番号に合わせることで、ファイル名の辞書順に並び替えると問題の順番と一致するようにしている。
