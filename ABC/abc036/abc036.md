## C - 座圧
https://atcoder.jp/contests/abc036/tasks/abc036_c

<details><summary>クリックで解説を開く</summary>

<br>

"abc036_c 1.py"では、`a` の要素ごとに `a_sorted` でのインデックスを求めているため、時間計算量が $`O(N^2)`$ となる。そのため、$`1 ≤ N ≤ 10^5`$ のテストケースでは間に合わない。$`1 ≤ N ≤ 10^3`$ であれば間に合う。

"abc036_c 2.py"では、`a[i]` に対応する答えとなるインデックスを、`ans` に格納している。$`0 ≤ a_i ≤ 10^9`$ のテストケースでは空間計算量が大きくなり不適。$`0 ≤ a_i ≤ 10^5`$ であればできる。

"abc036_c 3.py"・"abc036_c 4.py"では、dict型(辞書型)を用いている。どちらも内包表記を用いて `d` を作成しているが、"abc036_c 4.py"では `enumerate` を用いている。

"abc036_c 1.cpp"は、公式の解説と解法が似ている。setのキーが小さい順にソートして保管されていることを利用している。

"abc036_c 2.cpp"は、二分探索を用いている。
